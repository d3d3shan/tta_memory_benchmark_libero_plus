# Hugging Face Result Artifacts

These public datasets contain failure-grid MP4 videos plus JSON/MD metadata mapping each tile to task, episode, seed, difficulty, perturbation parameter, reward, and source path.

| Perturbation | Dataset |
|---|---|
| Camera Viewpoints | https://huggingface.co/datasets/d3d3shan/pi05-libero-plus-camera-view-failures |
| Robot Initial States | https://huggingface.co/datasets/d3d3shan/pi05-libero-plus-robot-initial-failures |
| Light Conditions | https://huggingface.co/datasets/d3d3shan/pi05-libero-plus-light-conditions-failures |

The GitHub repository only stores summaries and reproducibility scripts. Download videos from Hugging Face when needed.
